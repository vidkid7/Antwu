# ANTWU product contract

ANTWU serves transport workers, union members, journalists, partner organizations, and staff editors. The public information architecture includes the homepage, union introduction, organization chart, central/province/district/unit/international directories, updates, notices, documents, activities, gallery, blog, contact, and membership registration. English and नेपाली content share one persistent language switcher.

The visual system uses the supplied red union mark, warm paper, ink, documentary photography, grid lines, responsive editorial typography, and restrained motion. Public pages use real seeded content and explicit empty states where the source material has no records. The admin surface provides schema driven bilingual editing, media upload and cleanup, inbox review, JSON backup, and account security.

Run `npm run lint`, `npm run typecheck`, `npm run test`, `npm run test:integration`, and `npm run build` before release. Keep the SQLite database and media directory persistent in production.
